# Kebab Bro: сайт замовлення

Сайт для закладу Kebab Bro (м. Стрий, вул. Бобикевича 11/1). Гість обирає страви, оформлює доставку або самовивіз, оплата при отриманні. Замовлення надходить у Telegram персоналу.

Next.js (App Router), TypeScript, Tailwind CSS, Vitest.

## Запуск

```bash
npm install
cp .env.example .env.local   # заповніть значення нижче
npm run dev                  # http://localhost:3000
npm test                     # тести
npm run build                # продакшн-збірка
```

Без змінних середовища сайт працює, але замовлення не надходять: гість побачить повідомлення з телефоном закладу.

## Telegram

1. У Telegram відкрийте @BotFather, виконайте `/newbot`, збережіть токен.
2. Створіть чат або групу для персоналу й додайте туди бота.
3. Напишіть щось у чат і відкрийте `https://api.telegram.org/bot<TOKEN>/getUpdates`. Значення `chat.id` це `TELEGRAM_CHAT_ID` (у групи воно від'ємне).
4. Задайте змінні:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`

Токен використовується лише на сервері (`src/app/api/order/route.ts`) і не потрапляє в браузер.

## Деплой на Vercel

1. Імпортуйте репозиторій, у налаштуваннях проєкту вкажіть Root Directory `kebab-bro`.
2. У Settings, Environment Variables додайте обидві змінні Telegram.
3. Задеплойте. Після цього надішліть тестове замовлення.

Обмеження запитів (5 на хвилину з одного IP) працює в пам'яті сервера і є лише базовим захистом від спаму.

## Як змінити меню й ціни

Усе в одному файлі: `src/data/menu.ts` (страви, варіанти, додатки, зони доставки). Сервер перераховує суму за цим же файлом, тому змінені ціни автоматично діють і на сайті, і в замовленнях. Правила доставки та безкоштовного порогу: `src/lib/pricing.ts`, графік роботи: `src/lib/hours.ts` (і текст у `src/components/InfoSection.tsx`).

## Відомі прогалини в меню

Меню зібране з Instagram Highlights і сторіс власниці; потребує перевірки:

- немає ціни на порцію міксу в розділі «Додатки» (позицію не додано);
- «Картопляні діпи під сирним соусом з беконом» (144 грн) і «Картопляні діпи» (84 грн) — уточнити, чи це різні позиції;
- ціни бургерів і напоїв, яких немає в сторіс, не звірені з реальними;
- фото страв немає, картки показують назву, склад і ціну;
- графік у суботу: профіль каже «Пт-сб 10:00-23:00», а сторіз «Графік» лише «СБ». Використано дані профілю.
